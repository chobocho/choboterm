choboterm 작업 기록

2026-10-02 — 기술 스택 검토

  • 질문: Go + Wails + xterm.js 조합으로 SSH/Telnet 터미널을 만들고 X11 포워딩은 지원하지 않아도 되는지
  • 결론: 적합한 조합임. X11 미지원도 일반 용도에서는 문제없음 (PuTTY/Windows Terminal 대체 수준이라면 대부분 불필요)
  • 권장 라이브러리: golang.org/x/crypto/ssh, xterm.js + addon-fit/webgl/search/web-links, Telnet은 직접 구현(IAC 협상: NAWS, TTYPE, ECHO, SGA)
  • 주의점: Wails 이벤트 브리지의 출력 배칭(16ms 단위 등), UTF-8 경계 처리, 리사이즈 시 WindowChange, known_hosts 검증, ssh-agent(Windows는 OpenSSH named pipe/Pageant)

2026-10-02 — ZTerm 기능 호환성 검토

  • 결론: ZTerm 주요 기능은 모두 구현 가능. 단, 일부는 xterm.js 기본 기능이 아니라 직접 구현 필요
  • 쉬움: 주소록, 탭/다중 세션, 로그 저장, 스크롤백, ANSI 컬러, 자동 로그인
  • 직접 구현: EUC-KR/CP949 변환(Go x/text), Zmodem(sz/rz), 스크립트/매크로, BBS 번호 클릭 메뉴
  • 까다로움: 한글 IME 조합 표시, 동아시아 모호폭(─│ 등) 문자 2칸 처리 → 커스텀 unicode provider 필요

2026-10-02 — 프로젝트 생성 및 ZTerm 스타일 접속 창 구현

  • Wails v2(vanilla-ts) 프로젝트 생성, xterm.js(@xterm/xterm, addon-fit, addon-unicode11) 연동
  • 시작 시 ZTerm처럼 Host / Port / Login / Pass + Connect / Cancel 접속 창 표시 (Alt+C, Alt+A, Esc 지원)
  • Port 22 → SSH, 그 외 → Telnet 자동 판별 (Port 칸 오른쪽에 프로토콜 표시)
  • Host 콤보박스: 최근 접속 20개 기록(%AppData%\choboterm\hosts.json, 비밀번호는 저장 안 함)
  • SSH(ssh.go): 비밀번호, keyboard-interactive, ~/.ssh 개인키 인증, known_hosts 검증(처음 보는 호스트는 확인 창, 키가 바뀌면 차단)
  • Telnet(telnet.go): IAC 협상(NAWS/TTYPE/ECHO/SGA/BINARY), CR NUL 변환, login:/password: 프롬프트 자동 로그인
  • 출력은 16ms 단위로 묶어 base64 이벤트로 전달 (app.go pump)
  • 단축키: Ctrl+Shift+N 접속 창, Ctrl+Shift+D 연결 끊기, 연결이 끊긴 상태에서 Enter 누르면 다시 접속
  • 검증: go vet / go test(Telnet 협상·이스케이프·자동 로그인) 통과, wails build 성공, 실행 화면 확인. 실제 서버 접속 테스트는 미실시
  • 커밋 d6df82d (main). .gitignore에 /choboterm.exe, .idea/ 추가

2026-10-02 — EUC-KR(CP949) 인코딩 지원

  • 문제: EUC-KR 서버 접속 시 한글 깨짐 (xterm.js는 UTF-8만 해석)
  • codec.go: 수신 CP949→UTF-8 변환(청크 경계에서 잘린 2바이트 문자 보존), 송신 UTF-8→CP949 변환
  • CP949에 없는 문자는 '?'로 전송 (x/text의 ReplaceUnsupported는 0x1A=Ctrl+Z를 보내므로 사용 안 함)
  • 접속 창에 Code(UTF-8 / EUC-KR) 항목 추가, 접속 기록에 인코딩도 저장, 창 제목에 [인코딩] 표시
  • Ctrl+Shift+E: 접속 중 UTF-8 ↔ EUC-KR 즉시 전환
  • cjkwidth.ts: EUC-KR 모드에서 모호폭 문자(─│■○※ 등)를 2칸으로 그리는 xterm.js 유니코드 제공자(11-cjk) 추가 → BBS 박스 그림 정렬
  • 검증: codec 단위 테스트(분할 수신, CP949 확장 문자 '똠', 인코딩, UTF-8 통과) 통과, wails build 성공, 접속 창 확인. 실제 EUC-KR 서버 접속은 미확인

2026-10-02 — "unknown Unicode version 11-cjk" 오류 수정

  • 증상: EUC-KR로 접속은 되지만 접속 창에 오류가 뜨고 창이 닫히지 않음
  • 원인: xterm.js의 term.unicode는 접근할 때마다 새 객체를 반환 → 인스턴스의 register를 가로채도 애드온은 다른 객체를 써서 Unicode 11 제공자를 못 잡음 → 11-cjk 미등록
  • 수정: 공유 프로토타입의 register를 가로채도록 변경(cjkwidth.ts). 등록에 실패해도 접속은 막히지 않도록 applyEncoding에서 등록 여부 확인
  • 검증: 실행 화면에서 versions=6,11,11-cjk 확인, WIDE 모드에서 ─│■○※가 2칸 폭으로 배치되는 것 확인(임시 디버그 코드는 제거)
  • 남은 문제: 2칸 폭 셀 안에서 ─ 같은 선 문자가 1칸 길이로 그려져 가로선이 끊겨 보일 수 있음
  • 커밋 0313e6f (main): EUC-KR 지원 + 11-cjk 오류 수정 (이전 커밋 이후 기록한 history.html 변경도 포함)

2026-10-03 — 1단계: SFTP 파일 전송

  • filexfer.go: 공통 RemoteFS 인터페이스(Getwd/List/Download/Upload/Close), 진행률(100ms 단위 xfer:progress 이벤트), 취소, 다운로드 기본 위치 ~/Downloads
  • sftp.go: 기존 SSH 연결 위에 SFTP 채널을 열어 재로그인 없이 사용 (pkg/sftp), 심볼릭 링크 폴더 처리
  • files.ts: 파일 전송 창 — 경로 입력, 상위 폴더, 새로 고침, 더블클릭/Enter로 폴더 이동·다운로드, 여러 파일 업로드, 키보드(↑↓ Home End Enter Backspace F5 Esc)
  • 진행률 상자: 파일 창이 열려 있으면 창 안에, 아니면(Zmodem 등) 오른쪽 아래에 표시. 속도 표시, 취소 버튼
  • 단축키 Ctrl+Shift+F (SSH 접속 중). Telnet이면 sz/rz 사용 안내
  • 수정: main.ts 안내 문구에 줄바꿈/ESC가 이스케이프 대신 실제 제어문자로 들어가 있던 것 복구
  • 검증: 프로세스 내 SSH+SFTP 서버로 목록/다운로드/1MB 업로드 테스트 통과, 화면 레이아웃 확인(임시 데이터). 실제 서버에서 GUI 조작은 미확인

2026-10-03 — 2단계: FTP

  • Port 21 → FTP (접속 창 Port 칸에 FTP 표시). 터미널 없이 바로 파일 전송 창이 열리고, 창을 닫으면 연결을 끊고 접속 창으로 돌아감
  • ftp.go: jlaffaye/ftp 사용, Login이 비면 anonymous 로그인, 60초마다 NOOP으로 연결 유지(전송 중엔 생략)
  • Code가 EUC-KR이면 파일/폴더 이름을 CP949로 변환해서 송수신 (codec.DecodeString / EncodeString)
  • Connect가 사용한 프로토콜을 반환하도록 변경, FTP 접속 시 창 제목 ftp://host:port
  • 검증: pyftpdlib(CP949 모드) 로컬 서버로 한글 이름 목록/다운로드/900KB 업로드·재다운로드 테스트 통과 (ftp_test.go, CHOBOTERM_FTP_TEST 환경변수 있을 때만 실행)
  • 미지원: FTPS(TLS), 이어받기
