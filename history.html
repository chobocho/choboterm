  • 증상: 리눅스 설정 창의 "한국어" 등 select 글자가 아래로 내려가 잘림. 원인: WebKitGTK는 select를 GTK 버튼(자체 여백)으로 그리는데 높이가 22px 고정, Noto CJK 한글은 줄 높이가 커서 더 잘림(앞서 넣은 글꼴 목록 때문에 오히려 심해짐)
  • 수정: 리눅스에서만 select를 기본 모양 대신 입력칸처럼(appearance none + SVG 화살표, 줄 높이 20px) 그림. Windows는 그대로
  • 확인: WSL에 python3-gi-cairo · gir1.2-webkit2-4.1을 잠시 설치해 WebKitGTK 4.1로 설정·접속·포트 포워딩 창 HTML을 직접 렌더링(수정 전 재현 → 수정 후 정상, Save 버튼 한 줄도 확인). 확인 후 새로 설치한 패키지만 정확히 제거

2026-10-10 — 리눅스 버전 (tar.gz, 키링, macOS 미지원)

  • WSL에 Go 1.26.3·Wails CLI(~/sdk), gnome-keyring·xdotool·imagemagick·fonts-noto-cjk 설치. 원래 코드도 리눅스 빌드는 됐고 실패 테스트는 비밀번호 저장 2개·Lua 메모리 1개뿐
  • localpty_linux.go(creack/pty): bash·zsh·fish·sh 로컬 탭, 이 PC의 docker exec 탭. 셸 목록·명령줄 인용을 localshell_windows/unix로 분리
  • secret_linux.go: 키링(Secret Service)에 둔 키로 AES-GCM. 키링 없으면 저장 안 함(테스트는 건너뜀). luajob_linux.go: /proc로 메모리 감시해 한도 넘으면 종료, Pdeathsig로 앱과 함께 종료
  • 폴더 열기 xdg-open, 리눅스 창 아이콘. 화면: platform.ts로 반투명·PuTTY 가져오기 숨김, 셸 안내·글꼴 대체·문구(시스템 언어, 키링) 정리
  • WSLg로 실제 실행: 접속 창, bash 탭(색상), 설정, 도커 창, 컨테이너 셸 확인. 도커 창 체크박스 겹침 발견·수정(.body input 100% 폭이 WebKitGTK에서 체크박스를 넓힘). 참고: 테스트 시 앱을 setsid로 띄워야 wsl.exe 종료와 함께 WebKit 프로세스가 죽지 않음
  • build_linux.sh: Ubuntu 22.04 컨테이너에서 테스트·빌드(GLIBC 2.34까지만 요구, 22.04에서 라이브러리 연결 확인) → release/choboterm-linux-amd64.tar.gz(실행 파일, 아이콘, .desktop, install.sh, README). .gitattributes로 sh는 LF. install.sh 임시 홈에서 확인
  • README: Linux 다운로드·요구 사항·파일 위치·빌드·릴리스 절차, macOS 미지원. 소개 페이지는 릴리스 때 갱신 예정

2026-10-09 — 도커 쪽 같은 문제 점검

  • 중복 없음: 컨테이너 탭은 저장·자동 시작이 없고 탭마다 셸 세션 하나(의도된 동작). 포트 열기는 ForwardAdd를 거쳐 같은 서버 탭에 대기로 공유되고, 대기 규칙도 "이미 있음"으로 봐서 다시 추가하지 않음
  • 보완: 컨테이너 탭을 연 원래 탭이 닫힌 뒤 Enter로 다시 열 때, 같은 서버(host·port)에 접속한 다른 탭이 있으면 그 탭의 접속을 사용

2026-10-09 — 포트 포워딩: 같은 서버 여러 탭 중복 수정

  • 원인: 규칙은 호스트별 저장인데 접속할 때마다 restoreForwards가 탭마다 모든 규칙을 시작
  • 수정: 같은 서버(host·port)의 탭 중 한 탭만 수신, 나머지는 "대기 (다른 탭에서 수신 중)". 수신 탭이 끊기거나 닫히면 대기 탭이 이어받음. 한 탭에서 추가·삭제하면 다른 탭에도 반영. App.fwdMu로 결정 과정 직렬화
  • 테스트 TestForwardOneTabPerHost: 탭 2개 수신/대기, 나중에 연 3번째 탭 대기, 1번 탭 닫으면 이어받아 실제 통신, 삭제 시 모든 탭에서 제거·수신 중지
  • 참고: V0.2.8 릴리스 직후 Pages 반영 확인은 중단됨(릴리스 커밋 빌드는 errored, 다음 커밋 빌드 진행 중이었음)
