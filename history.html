2026-10-03 — MobaXterm 대비 부족한 기능 검토 (X11 제외)

  • SSH 인증: ssh-agent/Pageant 미지원, 암호 걸린 개인키 미지원, 키 파일 직접 지정 불가, SSH 비밀번호 저장 불가
  • 접속 경로: 점프 호스트(ProxyJump/게이트웨이), HTTP/SOCKS 프록시 경유 접속 없음
  • 세션 관리: 세션 트리(폴더·이름·세션별 설정) 없음, 최근 20개 기록만 있음. 가져오기/내보내기(PuTTY 등) 없음
  • 세션 종류: 로컬 셸(cmd/PowerShell/WSL), 시리얼(COM), RDP/VNC, Mosh, Rlogin 없음
  • 터미널: 분할 창, MultiExec(여러 탭 동시 입력), 세션 로그 저장, 색 테마/글꼴 선택, 스크롤백 크기 설정 없음
  • 파일: SSH 사이드바 SFTP 탐색기(현재 폴더 따라가기), 원격 파일 바로 편집(저장 시 업로드), 동기화 없음
  • 기타: 독립 터널 관리자(MobaSSHTunnel), 네트워크 도구, 휴대용 설정 파일 등
  • 추가 설명: 세션 로그 = 접속 중 수신 출력을 실시간으로 파일에 계속 기록(자동/수동, 파일명 패턴, 이스케이프 제거 옵션). 스크롤백 한도와 무관하게 전체 기록이 남음

2026-10-03 — 세션 로그 기능

  • 일반 텍스트 모드(기본): CSI/OSC/DCS 등 이스케이프·제어 문자 제거, \r·\b·ESC[K·커서 좌우 이동을 현재 줄에 적용(진행률은 마지막 상태만), 청크 경계에서 잘린 이스케이프·UTF-8 처리. 원본 모드는 이스케이프 포함 저장
  • 접속/재접속/끊김/종료 시각을 '===== 시각 내용 =====' 구분선으로 기록. 재접속해도 탭을 닫기 전까지 같은 파일에 이어 씀
  • 설정: logAuto(접속마다 자동 기록), logRaw, logDir(찾아보기 = 폴더 선택 창). 바인딩 StartLog/StopLog/LogPath/ShowLogs(탐색기에서 파일 선택)/ChooseLogDir, 이벤트 log:changed
