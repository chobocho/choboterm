choboterm 작업 기록

2026-10-02 — 기술 스택 검토

  • 질문: Go + Wails + xterm.js 조합으로 SSH/Telnet 터미널을 만들고 X11 포워딩은 지원하지 않아도 되는지
  • 결론: 적합한 조합임. X11 미지원도 일반 용도에서는 문제없음 (PuTTY/Windows Terminal 대체 수준이라면 대부분 불필요)
  • 권장 라이브러리: golang.org/x/crypto/ssh, xterm.js + addon-fit/webgl/search/web-links, Telnet은 직접 구현(IAC 협상: NAWS, TTYPE, ECHO, SGA)
  • 주의점: Wails 이벤트 브리지의 출력 배칭(16ms 단위 등), UTF-8 경계 처리, 리사이즈 시 WindowChange, known_hosts 검증, ssh-agent(Windows는 OpenSSH named pipe/Pageant)

2026-10-02 — ZTerm 기능 호환성 검토

  • 결론: ZTerm 주요 기능은 모두 구현 가능. 단, 일부는 xterm.js 기본 기능이 아니라 직접 구현 필요
  • 쉬움: 주소록, 탭/다중 세션, 로그 저장, 스크롤백, ANSI 컬러, 자동 로그인
  • 직접 구현: EUC-KR/CP949 변환(Go x/text), Zmodem(sz/rz), 스크립트/매크로, BBS 번호 클릭 메뉴
  • 까다로움: 한글 IME 조합 표시, 동아시아 모호폭(─│ 등) 문자 2칸 처리 → 커스텀 unicode provider 필요

2026-10-02 — 프로젝트 생성 및 ZTerm 스타일 접속 창 구현

  • Wails v2(vanilla-ts) 프로젝트 생성, xterm.js(@xterm/xterm, addon-fit, addon-unicode11) 연동
  • 시작 시 ZTerm처럼 Host / Port / Login / Pass + Connect / Cancel 접속 창 표시 (Alt+C, Alt+A, Esc 지원)
  • Port 22 → SSH, 그 외 → Telnet 자동 판별 (Port 칸 오른쪽에 프로토콜 표시)
  • Host 콤보박스: 최근 접속 20개 기록(%AppData%\choboterm\hosts.json, 비밀번호는 저장 안 함)
  • SSH(ssh.go): 비밀번호, keyboard-interactive, ~/.ssh 개인키 인증, known_hosts 검증(처음 보는 호스트는 확인 창, 키가 바뀌면 차단)
  • Telnet(telnet.go): IAC 협상(NAWS/TTYPE/ECHO/SGA/BINARY), CR NUL 변환, login:/password: 프롬프트 자동 로그인
  • 출력은 16ms 단위로 묶어 base64 이벤트로 전달 (app.go pump)
  • 단축키: Ctrl+Shift+N 접속 창, Ctrl+Shift+D 연결 끊기, 연결이 끊긴 상태에서 Enter 누르면 다시 접속
  • 검증: go vet / go test(Telnet 협상·이스케이프·자동 로그인) 통과, wails build 성공, 실행 화면 확인. 실제 서버 접속 테스트는 미실시
